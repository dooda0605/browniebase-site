가장 큰 문제
기상 앱 랜딩인데 앱 화면이 한 장도 없습니다. 대신 이모지가 36개입니다 — 기능 8 + 활동 4 + 히어로 필 3 + 국기 21. 가장 강한 자산(등급 지도·예보표)이 빠진 자리를 이모지가 채우고 있습니다.
앱과 같은 팔레트
현재는 흰 배경 + cyan-50/teal-50 그라데이션인데 앱은 다크 우선입니다. 스토어에서 앱을 받으면 완전히 다른 화면이 나옵니다. deep950 · ocean · 등급색을 그대로 써서 랜딩과 앱이 이어지게 했습니다.
헤드라인의 "AI로"
지금은 <span>AI</span>로 바다 들어가기 전…으로 붙어 "AI로 바다 들어가기"처럼 읽힙니다. 헤드라인은 사용자의 질문("들어가도 되나?")으로 바꾸고, AI·차폐 알고리즘은 기능 섹션의 근거로 내렸습니다.
A~E를 먼저 설명
앱의 핵심 발명은 등급 한 글자인데, 현재 랜딩에는 "A~E 등급"이라는 말만 있고 A가 뭔지 어디에도 없습니다. 히어로 다음에 5장 카드로 두었습니다 — 스토어에 오기 전에 이걸 이해해야 앱이 이해됩니다.
국기 칩 21개 → 지도
5열 × 5줄 칩 벽은 "21개"라는 사실만 반복합니다. 지도 + 국가별 개수 6줄로 바꾸면 어디를 덮는지가 한눈에 보입니다.
앱과 불일치 — 확인 필요
랜딩의 활동 이모지가 앱과 다릅니다. 랜딩은 프리다이빙 🐠 · 스쿠버 🌊인데, 앱 constants.dart의 Activity.icon은 프리다이빙 🧜 · 스쿠버 🐠입니다. 앱 기준으로 맞췄습니다.
필요한 것
히어로 목업과 기능 카드의 화면은 제가 그린 플레이스홀더입니다. 실제 앱 스크린샷 4~5장(홈·지도·스팟 상세·경고)을 주시면 그 자리에 넣겠습니다. 지역 지도도 실제 지형 데이터로 교체해야 합니다.
